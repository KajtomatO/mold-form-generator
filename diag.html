Printer check

Eight small molds with the real taper, ridge and groove, to find the clearances for your printer and to test for leaks. The README in the ZIP says how to read the result.

A taper too tight stops the base whatever the groove does, so the groove pairs are built at the taper clearance below. Print the taper pairs first. If the best one is not the value shown here, enter it and download again for the groove pairs.
